Conectar una cuenta

Autoriza la cuenta de TikTok de una marca para que Automatizacion Contenido pueda identificarla. Elegí primero a qué marca corresponde la cuenta de TikTok que vas a conectar — este primer paso solo lee la información básica de perfil (nombre de usuario/avatar) para confirmar qué cuenta quedó conectada, no publica ni modifica nada todavía.

Ya conectaste una cuenta y querés ver la demo de subida (App Review, Sandbox): TikTok Integration Demo.
