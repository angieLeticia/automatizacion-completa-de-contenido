Política de Privacidad

Automatizacion Contenido

Última actualización: 12 de septiembre de 2026

1. Introducción

Esta Política de Privacidad explica, de manera general, cómo Automatizacion Contenido trata la información necesaria para proporcionar sus funciones de organización, gestión, autenticación e integración con plataformas externas.

2. Información que puede procesarse

Dependiendo de las funciones utilizadas, el servicio puede procesar las siguientes categorías de información:

  • información básica de cuentas conectadas;
  • identificadores proporcionados por plataformas externas;
  • información necesaria para autorizar integraciones;
  • contenido proporcionado por el usuario;
  • metadatos relacionados con contenido y publicaciones;
  • información técnica necesaria para seguridad, funcionamiento y diagnóstico.

3. Información de autenticación

Cuando el usuario conecta una plataforma mediante OAuth, pueden procesarse credenciales o tokens de autorización necesarios para mantener la conexión y ejecutar las acciones autorizadas.

Estas credenciales deben tratarse como información sensible y utilizarse únicamente para las funciones autorizadas por el usuario.

4. Cómo utilizamos la información

La información puede utilizarse para:

  • autenticar cuentas conectadas;
  • verificar la identidad de una cuenta;
  • organizar y gestionar contenido;
  • preparar contenido para publicación;
  • ejecutar acciones solicitadas y autorizadas por el usuario;
  • mantener el estado de procesos y publicaciones;
  • detectar errores y mejorar la seguridad del servicio.

5. Plataformas de terceros

Cuando el usuario conecta servicios como TikTok, YouTube, Instagram, Facebook u otras plataformas, parte del procesamiento ocurre mediante las APIs y servicios de dichas plataformas.

Cada plataforma mantiene sus propias políticas de privacidad, términos y controles de datos. El usuario debe consultar también las políticas de cada servicio que decida conectar.

6. Contenido del usuario

El contenido proporcionado al servicio puede incluir archivos de vídeo, audio, imágenes, textos, metadatos y otra información necesaria para preparar o gestionar publicaciones.

El servicio utiliza dicho contenido únicamente en la medida necesaria para proporcionar las funciones solicitadas por el usuario y mantener el funcionamiento del sistema.

7. Compartición de información

La información puede enviarse a una plataforma externa cuando dicha transferencia sea necesaria para ejecutar una función que el usuario haya autorizado, por ejemplo, autenticar una cuenta o publicar contenido mediante una API.

No se pretende vender información personal del usuario a terceros.

8. Seguridad

Se aplican medidas técnicas destinadas a proteger la información contra acceso, modificación o divulgación no autorizados.

Ningún sistema conectado a Internet puede garantizar seguridad absoluta. Por ello, no puede garantizarse que la información permanezca completamente libre de cualquier incidente de seguridad.

9. Conservación de información

La información puede conservarse durante el tiempo necesario para proporcionar las funciones solicitadas, mantener registros técnicos, cumplir obligaciones aplicables o resolver incidencias.

Los periodos concretos de conservación pueden variar según el tipo de información y la finalidad para la que fue recopilada.

10. Eliminación y solicitudes del usuario

Los usuarios pueden solicitar información sobre los datos asociados a sus interacciones con el servicio y, cuando sea técnicamente y legalmente posible, solicitar su eliminación.

Las solicitudes relacionadas con datos mantenidos directamente por plataformas externas pueden requerir gestionarse también mediante los mecanismos de privacidad de dichas plataformas.

11. Transferencias internacionales

Algunos proveedores tecnológicos y plataformas externas pueden procesar información en países distintos del país donde se encuentra el usuario. Dicho procesamiento puede estar sujeto a las leyes y mecanismos de protección de datos correspondientes.

12. Menores

Automatizacion Contenido no está diseñado específicamente para recopilar información personal de menores. No se debe utilizar el servicio para proporcionar información personal de menores cuando dicho tratamiento no esté permitido por la legislación aplicable.

13. Cambios en esta política

Esta Política de Privacidad puede actualizarse cuando cambien las funciones del servicio, las integraciones, los requisitos legales o las prácticas de seguridad. La fecha de actualización se mostrará en esta página.

14. Contacto

Para consultas relacionadas con privacidad y protección de datos, utilice el canal de contacto oficial publicado junto con la información del proyecto Automatizacion Contenido.

15. Relación con TikTok y otras plataformas

Automatizacion Contenido es independiente de TikTok, YouTube, Meta, Instagram, Facebook y otras plataformas externas. Esta política no sustituye las políticas de privacidad de dichas plataformas.
